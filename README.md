# 👨‍💻 Portfolio Web - Ounays Mayeux

Ce dépôt contient le code source de mon portfolio personnel. Il s'agit d'un site web statique "one-page" conçu pour présenter mon parcours en BUT Informatique, mes compétences techniques et mes projets.

## ✨ Fonctionnalités Principales
* **Thème dynamique :** Bascule claire/sombre automatique (détection des préférences système) et manuelle via un bouton dédié.
* **Design Adaptatif (Responsive) :** Mise en page fluide optimisée pour écrans de bureau, tablettes et smartphones grâce à CSS Grid et Flexbox.
* **Composants intégrés :** Lecteur audio natif pour une présentation vocale, bouton flottant pour le téléchargement direct du CV, et intégration iFrame Google Maps.
* **Performances optimisées :** Aucune dépendance externe (zéro framework lourd) et encodage des images (logo, profil) directement en Base64 pour réduire les requêtes HTTP.

## 🛠️ Technologies Utilisées

| Technologie | Rôle dans le projet |
| :--- | :--- |
| **HTML5** | Structure sémantique du document (`<header>`, `<main>`, `<section>`, `<article>`). |
| **CSS3** | Mise en forme complète, gestion des thèmes via les variables natives (`:root`), et effets visuels (`backdrop-filter`). |
| **JavaScript** | Logique d'interactivité purement native pour l'alternance et la sauvegarde du thème visuel. |

## 📂 Contenu du Site
* **À propos :** Présentation globale et lecture audio.
* **Parcours & Expériences :** Chronologie des diplômes (BUT, Bac, Brevet) et des engagements associatifs (MDL, CVL, CA).
* **Compétences :** Indicateurs de niveau pour les langages de programmation (Python, SQL, HTML/CSS, Java, Bash) et langues vivantes.
* **Projets :** Cartes détaillant les réalisations académiques (Puissance 4, gestion de BDD, robot minier).
* **Contact :** Coordonnées directes, accès LinkedIn et géolocalisation.

## 🚀 Installation et Déploiement

Ce projet est statique et ne requiert aucune compilation ni serveur local complexe.

1. Clonez ou téléchargez ce dépôt sur votre machine.
2. Assurez-vous que les fichiers annexes suivants sont bien présents à la racine du projet, au même niveau que le fichier `index.html` :
   * `CV_Ounays_MAYEUX.pdf`
   * `Audio_Portfolio.m4a`
3. Ouvrez le fichier `index.html` directement dans votre navigateur web pour visualiser le site.
